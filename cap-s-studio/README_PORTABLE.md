# Cap-s data analysis

CAP-S 專用 Python／Tk 程式：每組一條平均曲線，搭配半透明誤差區域。預設 **Mean ± SEM**，可切換 SD；Excel 原始檔不會被修改。

此程式的入口是本資料夾的 `main.py`，套件為 `cap_s/`，與舊 `Python version/skin_analysis/`、`desktop-tauri/` 使用不同產品名稱與打包入口。介面只提供組別、單位、誤差帶、製圖與匯出。

## 開啟程式

- **macOS 原生包**：解壓縮後開啟 `CapSStudio.app`。不需要安裝 Python；包名標示 `arm64` 或 `x86_64`，需符合電腦架構。本機製作的包未經 Apple 公證；如系統阻擋，依 macOS 的「隱私權與安全性」提示允許開啟。
- **Windows 原生包**：解壓縮完整資料夾，再開啟 `CapSStudio.exe`。`_internal` 必須與 exe 放在一起。學弟妹不需要安裝 Python，也不需要網路。Windows 包必須在 Windows 建置、測試；macOS 包無法當成 exe 使用。
- **小體積原始碼包**：Windows 雙擊 `run_windows.bat`；macOS 可在 Terminal 執行 `zsh run_macos.command`。首次需要 Python（Windows 3.11+；macOS 3.12+ 且含 Tk）與網路，自動安裝三個直接依賴。之後使用同一啟動檔，通常不再需要網路。這個包不包含 Python runtime。

啟動腳本會先檢查 Python 版本與 Tk。macOS 有多個 Python 時，會略過不支援 Tk 的版本；已有虛擬環境但缺少 Tk 時，會提示修復環境，避免反覆安裝無法補上 Tk 的 Python 套件。

macOS 開發與封裝使用 Python 3.13 + 對應 Tk，建議維護者使用此版本系列。原生分享包已包含自己的 runtime，學弟妹電腦上的其他 Python 不會影響它。

## 三步製圖

介面一次只顯示一個步驟，標題下方會標示目前進度：

1. **選擇資料夾**：只顯示資料夾選擇與路徑欄。選擇資料夾後會讀取資料；也可貼上路徑，再按「下一步：勾選組別」。找到含 Excel 的實驗組後才會進入第二步。
2. **勾選組別**：顯示可比較的組別與已選數量；雙擊組別名稱可修改圖例。至少勾選一組後，按「下一步：製圖與匯出」。
3. **製圖與匯出**：此時才顯示單位、SEM／SD、圖表標題及進階設定。按「製作誤差區域圖」，完成後才顯示圖片與 CSV 匯出按鈕。

可按「上一步」返回修改。變更資料夾、組別、單位或時間參數後，會清除舊圖的預覽並收起匯出按鈕；重新製圖完成後才能匯出，避免誤用先前的結果。找不到資料或全不選時無法進入下一步。

### 分析進度與雲端資料

分析時會顯示目前檔案、已處理／總檔數、處理階段與經過秒數。若某次讀取持續超過 10 秒，會提示檔案讀取可能正在等待；這只能提示等待位置，不能直接判定是 OneDrive、Excel 內容或其他原因。「分析明細／注意事項」列出逐檔讀取與訊號處理耗時；讀取耗時也包含 Excel 解析，不能當作純下載時間。

可按「取消分析」。取消會捨棄未完成結果，於安全檢查點停止；若系統正阻塞在雲端開檔或讀取，必須等該次作業返回，因此不保證立刻停止。雲端資料若反覆等待，可先透過同步軟體完整下載，或複製到本機資料夾後再選取。

程式會在記憶體內暫存成功讀取的 Excel 數值，最多 64 MiB。重複製圖時，檔案路徑、大小與修改／狀態時間皆未變才重用；不暫存失敗檔案、不寫入原始資料，關閉程式即釋放。更改單位或時間參數仍會重新分析數值。讀檔時依工作表實際資料列讀取，避免儲存的過大範圍造成多餘空列掃描；中間缺值仍視為錯誤。

### 圖例與顏色

製圖完成後，按「圖例與顏色…」：

- 選擇組別並挑選顏色，曲線與陰影會同步變更。
- 圖例可放右側／下方圖外、圖內各角落或上下中央，也可隱藏。
- 欄數可設 1–4，字級可設 6–18；可恢復預設。
- 預設放在右側圖外，並提供 16 個預設顏色；不再自動搜尋最佳位置，減少密集曲線的繪圖負擔。
- 「顯示 Mean ± SEM／SD 文字」**預設關閉**。開啟後才在圖上顯示該文字，並跟隨目前 SD／SEM 選項；不影響曲線與誤差陰影。
- 「同組使用同一顏色」**預設關閉**。開啟後可選擇「Excel 所在資料夾名稱」或「上層資料夾名稱」作為分組依據，下表的「同色組」欄會預覽每條曲線的分組。

以 `1%/2 micro L/1.xlsx` 為例，「Excel 所在資料夾名稱」是 `2 micro L`，會讓不同濃度下同名的 `2 micro L` 同色；「上層資料夾名稱」是 `1%`，會讓 `1%` 下的不同劑量同色。預設分組依據為上層資料夾名稱，需先開啟同組同色才會使用。

分組以資料夾名稱完全相同為準，支援 `%`、`ppm`、`µM`、Control 或其他任意文字，不解析或換算單位。不同路徑／日期下同名的資料夾也會共用顏色；各曲線的樣本、n、平均與誤差仍分別保留。以實際 Excel 所在資料夾取名，即使選定根目錄本身直接含 Excel 也可使用；修改圖例文字不影響分組。

開啟同組同色時，挑選任一曲線的顏色會同步套用到目前同色組。逐曲線自訂色、依 Excel 資料夾名稱的同組色，以及依上層名稱的同組色分別保留；切換分組依據或關閉同組同色可回到該模式的配色。「恢復預設」清除所有自訂色並關閉這兩個選項。

按「套用」即可更新，不需重新讀取 Excel。設定保留至本次使用結束；選擇不同根目錄會恢復預設。圖例也可直接拖曳；圖片匯出沿用目前位置與顏色。再次重繪（例如改標題或切換 SEM／SD）會恢復設定中的圖例位置。CSV 的科學數值不受外觀設定影響。

資料格式沿用原專案：

```text
ROOT/
  2 uL/
    1.xlsx
    2.xlsx
  3 uL/
    1.xlsx
    2.xlsx
```

支援掃描**根目錄本身，以及往下最多三層資料夾**。例如選擇 `Dropping` 後，可找到 `20260606/pbs/組別A/1.xlsx`（組別 A 在第三層），也可直接選擇 `pbs`。每個直接包含 Excel 的資料夾各列為一組，父層與子層檔案不混合；組名顯示完整相對路徑，避免不同日期下的 `pbs` 被合併。根目錄本身含 Excel 時也可讀取，圖例顯示該根目錄名稱，CSV 的 `group` 欄記為 `.`。第四層以下不掃描，不跟隨子資料夾的符號連結；可改選更接近資料的根目錄。

每個 `.xlsx` 的第一個工作表必須有 `pF - Plot 0` 欄位；一個檔案視為一筆獨立重複樣本。中間缺值、非數字、公式未儲存計算結果等檔案會被略過並列入注意事項，不會刪掉該列而改變時間軸。Excel 的 `~$` 暫存檔會被忽略。

## 單位、誤差與對齊

- 預設 **ΔC（pF）**：每筆樣本先扣除自己的 baseline 平均值，再逐時間點平均。
- **相對變化（%）**：`(C − baseline) / baseline × 100`，baseline 為 0 時無法計算。
- **原始電容（pF）**：保留原始電容，再計算組平均。
- **SD**：樣本標準差，使用 `ddof=1`，顯示重複樣本的分散程度。
- **SEM**：`SD / √n`，顯示平均值的標準誤。兩者都是平均值加減誤差，不是 95% 信賴區間。
- 每筆樣本先以原有的反應偵測方法對齊至 `t=0`，各組只分析所有納入樣本共有的時間範圍，讓同組曲線全程維持相同 n；不補零，也不延伸較短檔案。組與組之間的時間範圍可能不同。
- n=1 時只畫曲線，不畫誤差區域；CSV 中 SD、SEM 與範圍欄位留空。

「進階」可調整取樣間隔、baseline 長度、施加時間與搜尋範圍。預設為 **0.1 秒／20 秒／25 ± 5 秒**；Excel 若使用不同取樣間隔，請先調整。這一版從取樣間隔建立時間軸，不讀取 Excel 的時間欄位。

修改資料、顯示單位或分析參數後，需重新製圖。SD／SEM、格線、標題與圖例可直接更新。匯出圖片使用目前畫面，PNG 為 300 dpi；CSV 包含 mean、SD、SEM、上下界、實際 n、來源檔名、圖例、設定及注意事項。匯出時會把類似試算表公式的組名、檔名和備註轉為純文字，避免開啟 CSV 時觸發公式；科研數值不變。

如果資料夾已有 `.skin_analysis_metadata.json`，程式會遵循原本有效的排除規則並回報排除項目，無需編輯原始資料。若 metadata 損壞，會暫停納入該組並提示修正，避免錯誤重新納入已排除樣本。這個精簡介面只讀取 metadata。

`ExampleData` 是固定亂數產生的 **合成示範資料**，不能當作實驗結果。

## 製作分享包（維護者）

先安裝 `requirements-error-band.txt` 與 `pyinstaller`，再執行：

```bash
python build_portable.py
```

Windows 可直接雙擊 `build_windows.bat`。交付檔預設放在專案的 `releases/cap-s/1.0.5/`，macOS 同時產出 DMG 與 ZIP，附 SHA-256；原始 App 在暫存目錄封裝，避免雲端同步的 Finder 資料影響簽名。打包只保留 TkAgg 繪圖後端，排除 Pandas、SciPy、舊版統計與 Qt/Jupyter；PyInstaller 僅在打包時使用。

```bash
python build_portable.py --source-only
```

可產出更小的 `releases/cap-s/1.0.5/CapSStudio-source.zip`，供已有 Python 的使用者使用。Windows exe 不能在 macOS 建置或完成原生驗證；分享前，請在 Windows 解壓完整包，使用示範資料確認載入、SD／SEM、圖片及 CSV 匯出。

維護者應先在**完整原始碼 Repository** 執行自動化測試，確認分享 ZIP 包含每個 Python 執行模組及所有合成樣本。分享 ZIP 不包含開發用 `tests/` 與測試依賴：

```bash
python -m pip install -r requirements-error-band.txt
python -m unittest discover -s tests -q
```

其中 `test_product_entrypoint.py` 驗證獨立 CAP-S 入口與原始碼 ZIP 的產品邊界；其餘測試涵蓋 Excel 讀取、誤差帶、排除規則與 CSV。這不等於原生 Windows/macOS GUI 的人工操作驗證。

# CAP-S 平均曲線與 SEM／SD 誤差區域

## 輸入與重複樣本

掃描選定根目錄本身及往下最多三層資料夾；每個直接含有 `.xlsx` 的資料夾各為一組實驗，每個檔案是一筆獨立重複樣本。以相對路徑區分不同層級或不同日期下的同名組別，不跨資料夾合併樣本；根目錄本身的組別在 CSV 的 `group` 欄記為 `.`，圖例使用根目錄名稱。不跟隨子目錄的符號連結。讀取第一張工作表的 `pF - Plot 0` 欄位。取樣間隔預設 0.1 秒，可在進階設定修改；不從 Excel 的時間欄推定間隔。中間缺值、布林值、文字或非有限數值會讓該檔案被略過並列出原因，避免刪除資料列後改變時間軸。

## 每筆樣本先處理，再計算組平均

1. 使用該樣本開頭的 baseline 視窗計算平均值 B；預設 20 秒。若與反應搜尋窗重疊，會縮短 baseline，並列出注意事項。
2. 沿用先前驗證的反應偵測：搜尋預設 25 ± 5 秒內，首次高於 B + 3 × baseline sample SD 的時間。找不到時依既有 fallback 搜尋，並保留警告；這是向上越過門檻的偵測，不能視為任何方向變化皆可辨識。
3. 各筆樣本先將偵測時間移至 t=0。
4. 依顯示單位轉換：ΔC 為 C−B；相對變化為 (C−B)/B×100%；Raw 使用 C。百分比模式不接受零 baseline。
5. 每組只保留所有納入樣本共有的時間範圍，以設定的取樣間隔建立網格，僅在各樣本有效範圍內插值。不外插、不補零；每組曲線全程使用相同 n。

## 平均值與誤差區域

每個共同時間點 t，對 n 筆納入樣本的轉換值 y 計算：

```text
mean(t) = sum(y_i(t)) / n
SD(t)   = sqrt(sum((y_i(t) - mean(t))²) / (n - 1))
SEM(t)  = SD(t) / sqrt(n)
```

預設陰影為 `mean ± SEM`，可切換 `mean ± SD`。SEM 是平均值標準誤，SD 是重複樣本的分散程度；均非 95% 信賴區間。n=1 時只畫曲線，SD／SEM 與上下界在 CSV 留空。每個 Excel 檔案必須代表適當的獨立重複；軟體不能由檔名驗證生物或技術重複的獨立性。

## 匯出與既有排除記錄

可匯出 PNG、PDF、SVG，以及包含 mean、SD、SEM、上下界、實際 n、來源檔名、圖例、設定與警告的 CSV。圖上每組的 n 與計算使用的樣本一致。CSV 文字欄保留既有的試算表公式跳脫處理。

程式只讀取已有 `.skin_analysis_metadata.json` 的排除記錄；不提供藥品資料編輯介面。若記錄損壞或與目前樣本數不相容，暫停該組並提示，不會重新納入原本排除的檔案。原始 Excel 與 metadata 不會因製圖而修改。

## 讀取進度與外觀設定

分析進度以已處理檔案數計算，包含依規則未納入的檔案，不代表實際樣本數 n。n 仍只計入成功讀取、通過檢查且未被排除的樣本。取消會捨棄本次未完成的組合結果。讀取階段耗時包含 Excel 解析或記憶體快取查詢，無法單獨據此判定雲端下載時間。快取上限 64 MiB，僅於檔案大小、修改與狀態時間未變時重用原始數值，分析參數仍重新計算；讀取範圍依實際工作表資料列，中間缺值仍會拒絕該檔案。

曲線／陰影顏色與圖例位置、字級、欄數僅影響呈現，不改變 SD／SEM 計算或 CSV 科學數值。固定圖例位置用來避免密集資料下的自動位置搜尋；目前未對使用者的雲端資料做效能量測。

「Mean ± SEM／SD」圖中文字為可選標示，預設隱藏，不影響誤差帶的計算與顯示。「同組使用同一顏色」也預設關閉；開啟後可依「Excel 所在資料夾名稱」或「上層資料夾名稱」配色。僅比較名稱原文，接受任意單位，不從名稱推論或換算濃度。不同路徑下同名資料夾會共用顏色；各資料夾的樣本、n、平均值與誤差範圍仍獨立計算，不會合併。分析用組別仍保留完整相對路徑，圖例文字修改也不改變配色分組依據。
